# Research and validation checklist

Use one checklist per issue. Start with a precise question and finish with an evidence packet that another researcher can reproduce.

1. [ ] **Scope the question.** Record the jurisdiction, courts, procedural posture, relevant dates, and factual assumptions. Mark disputed or unverified facts. Search external services with public citations and general legal questions. Keep private evidence in the matter workspace.
2. [ ] **Retrieve locally.** Start with exact citation and provision lookups, then search keywords and alternate terminology. Filter by court, region, year, and source type when useful. Keep the queries, filters, snapshot version, and candidate results. Download only the relevant corpus shards. Add semantic search when a compatible index is already available.
3. [ ] **Fill coverage gaps.** Compare the local snapshot with the dates and courts needed. Use official court portals and India Code for primary material. Use Vaquill India for targeted discovery and coverage checks. Use eCourtsIndia or the official eCourts portal to trace a docket or order by public case number or CNR. Search Indian Kanoon and Google for references that lead back to source texts.
4. [ ] **Run an independent search.** Give a fresh reviewer the question, jurisdiction, dates, and established statutory framework. Let it report results before showing it the first reviewer’s sources or conclusions. Gemini is one option. Ask for supporting and adverse authorities, precise citations, and explicit coverage gaps. Record whether the reviewer actually had web or database access.
   If an expected decision is missing, check the right shard, exact identifiers, and raw rows before calling it a corpus gap. A document in the raw data that the query missed is a retrieval miss. Keep model suggestions as unverified leads until you find the source text. If a service is unavailable or credit-limited, use official portals, public search, or provide the public source text to the reviewer and record the limitation.
5. [ ] **Verify against primary text.** For statutes, check the applicable version, commencement, savings, definitions, provisos, and exceptions that matter. For judgments, check court, date, citation, pinpoint, procedural posture, reasoning, and disposition. Distinguish submissions and quoted authorities from the court’s own reasoning. Search for appeals, review, overruling, and material distinctions. Record inaccessible sources and dates checked.
6. [ ] **Check each claim.** Pair each proposed proposition with the strongest verified passage and any material counterauthority. Record whether the passage supports, limits, contradicts, or leaves the proposition unresolved. Jev can help classify passage fit. Resolve disagreements by rereading the source and retain uncertainty where the record is incomplete.
7. [ ] **Draft and review.** Give the drafting model the relevant evidence rows and material qualifications. Ask for a pinpoint for each legal proposition and clear attribution for factual allegations. Have a separate reviewer compare the draft against the verified packet.
8. [ ] **Close the issue.** Record what was verified, what remains uncertain, and which downstream documents need an update. Reopen affected issues when new evidence or authority changes an answer.

Each tool serves a distinct purpose. Repeat a search when there is a gap it can fill. A record of search coverage and later treatment is part of the deliverable. Use the [evidence packet template](../templates/evidence-packet.md).
